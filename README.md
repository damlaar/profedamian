# ProfeDamián

Juego de ajedrez para chicos, de Damián Abel. Es una app web de un solo archivo (`index.html`) que funciona sin conexión una vez abierta. En tablets y celulares se puede tocar "Agregar a la pantalla de inicio".

Esta es la versión publicada. El código fuente y las pruebas viven en el repositorio de trabajo del proyecto, y esta página se arma con `publicar.py`.
